# VoicePlay - 声音魔法乐园

> 一个超酷的声音检测和互动项目，包含声纹识别、声音可视化、语音命令等有趣功能！

![VoicePlay Demo](demo.gif)

## ✨ 功能特点

### 🎯 声纹识别
- 🔍 **说话人识别** - 不管说什么都能认出是谁
- 📝 **声纹录入** - 轻松录入新用户声纹
- 🎵 **音频关联** - 为每个用户关联专属音频
- 🔄 **持续监听** - 实时检测并播放对应音频

### 🎨 声音可视化
- 📊 **实时频谱** - 炫酷的音频波形显示
- 🎆 **动态效果** - 声音触发的视觉特效
- 🎮 **互动游戏** - 对着麦克风控制游戏角色

### 🗣️ 语音命令
- 🎤 **语音控制** - 说话控制电脑
- ⚡ **快捷命令** - 自定义语音指令
- 🔧 **命令管理** - 添加/删除/编辑命令

### 🎪 趣味功能
- 🎭 **变声效果** - 实时变声（萝莉/大叔/机器人）
- 🔊 **音频特效** - 回声、混响等音效
- 🎮 **声音游戏** - 声控小游戏

## 🚀 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行项目

```bash
python main.py
```

## 📖 使用指南

### 1. 声纹识别
1. 打开应用
2. 在"声纹管理"中点击"录入声纹"
3. 输入姓名并对着麦克风说话
4. 可以为该用户设置触发音频
5. 开启"持续监听"，识别到用户时自动播放音频

### 2. 声音可视化
1. 切换到"可视化"标签
2. 对着麦克风说话
3. 观看炫酷的频谱动画

### 3. 语音命令
1. 切换到"语音命令"标签
2. 添加自定义命令（如"打开浏览器"）
3. 对着麦克风说出命令

### 4. 趣味功能
1. 切换到"趣味"标签
2. 选择变声效果
3. 录音并播放

## 🛠️ 技术栈

- **Python 3.8+** - 编程语言
- **Tkinter** - GUI框架
- **Librosa** - 音频处理
- **NumPy** - 数学计算
- **Sounddevice** - 音频输入输出
- **Matplotlib** - 可视化
- **Pygame** - 音频播放
