# 点门的人

子时，皇宫的门一扇一扇亮起来。

守门的兵换过三茬了，没人见过点门的人，只听说他穿一身灰衣，手里捏着一枚发光的令牌。每逢夜里，他便从午门开始，推开每一扇门，看一眼，再合上，然后走向下一扇。三十三扇门，一扇不落。

赵云守的银龙门是第七扇。他早就习惯了：灰衣人进来，绕着演武场转一圈，朝他虚点三下，又踢一踢角落的箭靶——后来他才知道，那叫"按键漫游"。第一次被摸时他挺枪便刺，枪尖停在灰衣人咽喉前三寸，对方眼皮都不抬。"假的，"灰衣人头也不回，"你砍不动我。"

赵云收了枪。他确实砍不动。这人没有血，没有名字，甚至没有梦。

可灰衣人有他的难处。第三十四扇门是重复的，第十九扇也是，第二十扇还是——三扇门后头连着同一个院子。他每晚都要在这三扇门前犹豫：点，是蠢；不点，又怕哪天哪扇门忽然换了院里的景。于是他学会了在门上做记号，同一座院子，只进去一次，然后在随身的册子上写："同文件，去重。"

最凶险的是第三十九扇。那扇门里是一座转盘，指针永远停在原地。灰衣人起初以为自己卡住了，站在门口试了三次，才明白：不是转盘不转，是没人摇它。他忽然有点想摇一摇，可他没有手——他的手只会按，不会抓。那一夜他在册子上多写了一行："静态画面，非故障。"

真正出过事的是第二十八号那晚。琉璃灯似的模块加载得极慢，门里的人还没登场，他已经把三张画影拓完走了。第二天翻册子，第一张画影里空无一人。他盯着那张空白看了很久，改了规矩：慢的门，多等一口气。后来再拓，三张齐了，画影里有山、有火、有打着伞的小孩。

灰衣人没有功劳簿。他的全部痕迹，是一份每日刷新的报告：三十三行，行行绿字。有同行劝他，写点血肉故事吧，谁爱看"OK 33，FAIL 0"？他摇头："我若写故事，说明门坏了。我最好的故事，就是没有故事。"

于是他继续推门。赵云在第七扇门里渐渐不怕他了，甚至会在他进来时把枪摆正——虽然他知道对方不看。转盘在第三十九扇门里静静等着某个摇它的人。而那份报告，在每一轮结束时安静地亮成一片绿色，像雪后初晴的瓦。

子时三刻，三十三扇门合完。灰衣人收起令牌，走入夜色。

无人点灯，但每一扇门都记得他来过。
