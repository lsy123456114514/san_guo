# 三国游戏 - GUI 打包工具使用说明

## 📖 简介

这是一个图形界面的打包工具，可以将你的三国游戏项目打包成 Windows 可执行文件 (EXE)，无需编写复杂的命令行参数。

## 🚀 快速开始

### 方法一：直接运行（推荐）

```bash
python 打包工具.py
```

### 方法二：打包成独立程序

```bash
# 打包成 EXE
pyinstaller GamePacker.spec

# 运行打包后的程序
dist\GamePacker.exe
```

## 🎯 功能特性

### 基本设置
- **项目路径**: 选择包含 main.py 的项目目录
- **主脚本**: 指定入口脚本文件名（默认: main.py）
- **输出名称**: 生成的 EXE 文件名（不含扩展名）
- **图标文件**: 选择自定义图标（支持 .ico 和 .png）

### 打包选项
- ✅ **单文件模式**: 将所有文件打包成单个 EXE
- ✅ **显示控制台**: 打包成控制台程序（用于调试）
- ✅ **UPX 压缩**: 启用 UPX 压缩减小文件体积
- ✅ **自动安装依赖**: 自动检测并安装 pyinstaller
- ✅ **清理旧构建**: 打包前自动清理 build 和 dist 目录

### 预设配置
工具提供 4 种预设配置，快速适配不同需求：

#### 🎮 游戏模式（推荐）
- 单文件模式
- 无控制台窗口
- UPX 压缩
- 适合最终分发

#### 📦 便携版
- 目录模式（不打包成单文件）
- 无控制台窗口
- 适合需要保留数据文件的版本

#### 🖥️ 控制台模式
- 单文件模式
- 显示控制台窗口
- 适合调试和开发

#### ⚡ 轻量模式
- 单文件模式
- 排除更多模块
- 最小化体积

### 高级选项
- **隐藏导入**: 指定需要手动导入的模块（逗号分隔）
- **排除模块**: 指定不需要打包的模块（逗号分隔）

## 📝 使用流程

### 1. 启动工具
```bash
python 打包工具.py
```

### 2. 配置设置
- 自动检测项目路径和图标
- 或手动浏览选择
- 选择预设或手动调整

### 3. 开始打包
- 点击 "🚀 开始打包" 按钮
- 观察日志输出
- 等待完成（通常 2-5 分钟）

### 4. 获取结果
- 打包成功后会自动打开输出目录
- 或者手动点击 "📂 打开输出" 按钮
- EXE 文件位于 `dist` 目录下

## 🔧 常见问题

### Q1: 打包失败怎么办？
**A**: 
- 查看日志输出中的错误信息
- 确保所有依赖都已安装
- 检查图标文件是否存在
- 尝试使用 "控制台模式" 查看详细错误

### Q2: 生成的 EXE 太大？
**A**: 
- 启用 UPX 压缩
- 排除不必要的模块
- 使用轻量模式预设
- 清理临时文件

### Q3: 杀毒软件报警？
**A**: 
- 这是正常现象，PyInstaller 打包的程序常被误报
- 使用 UPX 压缩会增加误报率
- 可以考虑添加数字签名
- 或提交误报给杀毒软件厂商

### Q4: 如何包含额外的文件？
**A**: 
- 在高级选项中调整 `--add-data` 参数
- 格式: `资源目录;目标目录`
- 例如: `--add-data "assets;assets"`

### Q5: 打包后程序无法运行？
**A**: 
- 检查是否缺少运行时依赖
- 查看打包日志中的警告信息
- 确保主脚本路径正确
- 尝试以管理员身份运行

## 💡 技巧

### 1. 加速打包
- 关闭杀毒软件的实时监控
- 使用 SSD 硬盘
- 排除不需要的模块

### 2. 减小体积
- 排除不需要的 Python 模块
- 使用 UPX 压缩
- 清理 build 目录

### 3. 提高兼容性
- 保持单文件模式
- 不要排除必要的模块
- 测试在不同 Windows 版本上运行
