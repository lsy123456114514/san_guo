# GitHub 分支标签管理工具

## 简介

这是一个用于管理 GitHub 仓库分支和标签的图形化工具，特别适合需要维护多个版本（如 C 和 Python 混合版本 / 纯 Python 版本）的项目。

## 功能特性

- **版本管理**: 支持快速切换和推送不同的代码版本分支
- **分支操作**: 创建、切换、删除本地和远程分支
- **标签管理**: 创建、推送、删除 Git 标签
- **自定义标签**: 支持自定义版本标签（如 v1.0、v2.0）
- **预设快捷标签**: 提供常用标签快速选择

## 界面说明

### 左侧面板 - 版本与标签设置

| 组件 | 说明 |
|------|------|
| 版本选择 | 选择目标版本（混合版/纯Python版） |
| 分支信息 | 显示当前分支和远程仓库 |
| 自定义标签 | 输入自定义版本标签 |
| 预设标签 | 快速选择常用标签 |

### 右侧面板 - 分支和标签列表

| 区域 | 功能 |
|------|------|
| 本地分支 | 显示所有分支，[C+Python] 标记混合版本，[Python] 标记纯Python版本 |
| 本地标签 | 显示所有本地标签 |

## 使用方法

### 1. 推送代码到指定分支

1. 选择目标版本（混合版/纯Python版）
2. （可选）输入自定义标签
3. 点击 **🚀 推送代码**
4. 确认推送信息
5. 等待推送完成

### 2. 创建新分支

1. 点击右侧 **创建分支** 按钮
2. 输入分支名称
3. 点击 **创建**

### 3. 切换分支

1. 在分支列表中选中目标分支
2. 点击 **切换分支**

### 4. 管理标签

**创建标签:**
1. 点击 **创建标签**
2. 输入标签名称和说明
3. 点击 **创建**

**推送标签:**
1. 在标签列表中选中目标标签
2. 点击 **推送标签**

**删除标签:**
1. 在标签列表中选中目标标签
2. 点击 **删除标签**
3. 确认删除

## 版本分支说明

| 版本 | 分支名 | 说明 |
|------|--------|------|
| C和Python混合版本 | `cpp-python` | 包含C扩展和Python代码 |
| 纯Python版本 | `python-only` | 纯Python代码，无C扩展 |

## 标签命名建议

推荐使用语义化版本格式：

- `v1.0` - 首个正式版本
- `v1.1` - 小幅更新
- `v2.0` - 重大版本更新
- `release` - 最新稳定版

## 注意事项

1. **推送前检查**: 确保已配置正确的远程仓库
2. **分支命名**: 避免使用特殊字符和空格
3. **标签推送**: 标签需要单独推送，不会随代码一起推送
4. **分支切换**: 切换分支会丢失未提交的更改，请先暂存

## 常见问题

### Q: 推送失败怎么办？

1. 检查网络连接
2. 确认 GitHub 仓库存在
3. 确认访问令牌有 repo 权限
4. 检查远程仓库地址是否正确

### Q: 如何查看所有分支？

点击 **🔄 刷新全部** 按钮更新分支列表。

### Q: 标签和分支有什么区别？

- **分支**: 用于开发过程中的代码分流
- **标签**: 用于标记特定的版本节点，通常用于发布

## 命令行参考

本工具底层使用的 Git 命令：

```bash
# 查看分支
git branch -a

# 创建并切换分支
git checkout -b <branch-name>

# 推送分支
git push -u origin <branch-name>

# 创建标签
git tag -a <tag-name> -m "message"

# 推送标签
git push origin tag <tag-name>
```
