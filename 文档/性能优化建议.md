# 三国游戏性能优化方案

## 一、项目现状分析

### 技术栈
- **渲染引擎**: Pygame + PyOpenGL (3D 地图)
- **语言**: Python
- **主要系统**: 2D UI、粒子特效、3D 场景、战斗系统等

### 性能瓶颈（基于代码分析）

1. **粒子系统**: 每帧创建大量 Surface 且无缓存
2. **3D 地图**: PyOpenGL 调用开销大
3. **UI 渲染**: 软件渲染模式下的大量绘制操作
4. **动画效果**: Python 循环计算开销

---

## 二、优化方案

### 方案 A: Python 内优化（快速见效，成本低）

#### 1.1 升级到 Pygame 2.0+
Pygame 2.0 已经默认使用硬件加速渲染，性能提升 2-3 倍。

```python
# 检查 Pygame 版本
import pygame
print(f"Pygame 版本: {pygame.version.ver}")
```

#### 1.2 粒子系统优化
当前代码每帧创建新 Surface，改为预缓存：

```python
# 优化前：每帧创建
def draw_particle(surface, x, y, size, color):
    surf = pygame.Surface((size*2, size*2), pygame.SRCALPHA)
    pygame.draw.circle(surf, color, (size, size), size)
    surface.blit(surf, (x-size, y-size))

# 优化后：预缓存
particle_cache = {}
def draw_particle_cached(surface, x, y, size, color):
    key = (size, color)
    if key not in particle_cache:
        surf = pygame.Surface((size*2, size*2), pygame.SRCALPHA)
        pygame.draw.circle(surf, color, (size, size), size)
        particle_cache[key] = surf
    surface.blit(particle_cache[key], (x-size, y-size))
```

### 方案 B: C++ 混合架构（高性能，成本中等）

#### 2.1 架构设计


#### 2.2 使用 Pybind11 创建 C++ 扩展

示例代码结构：

```cpp
// render_engine.cpp
#include <pybind11/pybind11.h>
#include <pybind11/numpy.h>
#include <SDL2/SDL.h>
#include <SDL2/SDL_opengl.h>

namespace py = pybind11;

class RenderEngine {
public:
    RenderEngine(int width, int height) {
        // 初始化 SDL 和 OpenGL
    }
    
    void render_particles(py::array_t<float> positions) {
        // C++ 高性能渲染粒子
    }
    
    void swap_buffers() {
        // 交换缓冲区
    }
};

PYBIND11_MODULE(render_engine, m) {
    py::class_<RenderEngine>(m, "RenderEngine")
        .def(py::init<int, int>())
        .def("render_particles", &RenderEngine::render_particles)
        .def("swap_buffers", &RenderEngine::swap_buffers);
}
```

编译命令（CMake）：
```cmake
cmake_minimum_required(VERSION 3.10)
project(render_engine)
find_package(pybind11 REQUIRED)
pybind11_add_module(render_engine render_engine.cpp)
target_link_libraries(render_engine PRIVATE SDL2 SDL2_opengl)
```

## 五、当前代码中的具体优化点

### game_main_menu.py 中的问题

1. **draw_three_kingdoms_background** 函数：
   - 每帧逐行绘制渐变背景 → 改为预先生成缓存 Surface
   - 每帧重新绘制云 → 改为预渲染并缓存

2. **DynamicLight** 类：
   - 每帧创建新 Surface → 预缓存不同大小的光晕

3. **ParticleSystem** 类：
   - 使用 Python 循环更新和渲染 → 改用 NumPy 向量化计算

### game_map_3d.py 中的问题

1. **PyOpenGL 调用**：
   - 频繁的 Python-C 切换 → 批量提交渲染命令
   - 未使用 Vertex Buffer Object (VBO) → 改用 VBO

## 六、快速验证测试

创建一个简单的性能测试脚本：

```python
import pygame
import time

def test_performance():
    pygame.init()
    screen = pygame.display.set_mode((800, 600))
    clock = pygame.time.Clock()
    
    # 测试粒子渲染性能
    particles = [(pygame.Rect(i*10, i*10, 5, 5), (255, 215, 0)) 
                 for i in range(1000)]
    
    start_time = time.time()
    frames = 0
    
    while frames < 100:
        screen.fill((0, 0, 0))
        for rect, color in particles:
            pygame.draw.circle(screen, color, rect.center, rect.width//2)
        pygame.display.flip()
        frames += 1
    
    elapsed = time.time() - start_time
    print(f"FPS: {frames / elapsed:.2f}")
    
    pygame.quit()

if __name__ == "__main__":
    test_performance()
```
